# DSv4-01 · 0731-w8a8 + DSpark · TP8（贪心主线）

8 卡 K100-AI 上 DeepSeek-V4-Flash（284B MoE，激活 13B）的单流最快形态。
2026-08-14 定稿的生产线固化包。

## 实测

| 指标 | 值 |
|---|---|
| 单流 decode（编程类） | **33.2 tok/s**（DSpark accept 4.38 / 0.68） |
| 23K prompt prefill | 437 tok/s |
| 并发 | 8/8、10/10 稳定（贪心） |
| KV 池 | 1,026,816 token |

以上为 2026-08-14 定稿时的数（P2P 禁用）。

### 2026-09-12：P2P 解禁后的实测

单变量 A/B，各 2 小时、同一套 harness（`bench/`）、同 seed、命中率 91.2% vs 91.7%
验明可比。**全面胜出，无一项回退**：

| 口径 | P2P 禁用 | **P2P 开启** | |
|---|---|---|---|
| 整机吞吐 | 231.7 请求/h | **293.7** | **+26.8%** |
| 并发 16 路 decode | 10.1 | **13.0** | **+28.7%** |
| 并发 8 路 decode | 14.2 | **18.1** | **+27.5%** |
| 单流 decode | 32.1 | **35.4** | +10.3% |
| 冷启 prefill | 524 | **775** | **+47.9%** |
| 起服就绪 | 1041s | **784s** | −24.7% |

规律是**并发越高收益越大**——并行度未变，唯一变的是卡间传输路径，
并发越高 all-reduce 越密集，主机内存两跳与 P2P 直连的差距越显。
详见 `docs/对照-101线P2P解禁-2026-09-12.md`。

> 上表取自标准 harness，与本节开头那组数口径不同（那是定稿时的专用脚本），
> **两者不可混用**。

### 超长上下文（2026-09-12，P2P 开启）

逐档实测全部受理：

| 目标 | 实际 prompt_tokens | 耗时 | prefill |
|---|---|---|---|
| 64K | 64,592 | 147.2s | 439 tok/s |
| 128K | 128,002 | 290.8s | 440 tok/s |
| 256K | 255,969 | 674.1s | 380 tok/s |
| **512K** | **511,903** | **1975.8s** | **259 tok/s** |

prefill 随长度明显衰减。512K 单请求耗时 **33 分钟**——远超 sglang 默认的
300 秒 watchdog，做这类验收**必须**另加 `--watchdog-timeout`，
否则不是客户端超时，是服务端把自己杀掉，现象看起来像「不支持」。

> ⚠ needle（长上下文检索准确性）**尚未有效验证**：首轮探针用了「校验口令」
> 字样，触发模型安全对齐而被拒答（512K 档答出了 needle 前半段，反证检索本身
> 是成功的）。已改为中性措辞待重测，在此之前**只能宣称"能受理 512K"，
> 不能宣称"512K 检索准确"**。

## 硬边界（必读）

0. **驱动必须已打 v4 补丁**（`hycu.ko` 的 `gpu_dma_buf_attach` 一字节改）。
   本线自 2026-09-12 起默认 `NCCL_P2P_LEVEL=SYS`；**未打补丁而开 P2P，
   跨 socket 会触发驱逐活锁**。若无法打补丁，请把 `serve.sh` 里该项改回
   `NCCL_P2P_DISABLE=1`（性能退回上表左列）。
1. **只在 temperature=0 稳定**。temp>0 且并发≥8 → GPU 硬件异常 0x1016，服务挂死需重启。
   缓解：网关对 temp>0 强制 `top_k=1`（数学等价贪心且实测稳定），或路由到 102 线。
2. **勿改 `--kv-cache-dtype`**：本线按 fp8 布局读 KV；bf16 会静默乱码且 accept 恒 1.00。
3. Think 需请求显式携带 `{"chat_template_kwargs": {"thinking": true}}`。
4. 就绪约 14 分钟；就绪后**先热身两次**再测（首次生成受 JIT 污染必偏慢）。

## 镜像与权重

- 镜像：`custom:sglang0.5.12-…-20260804-0006-deepseekV4-0811`（harbor，S2 自动拉取）
- 权重：`$DSV4_MODELS_ROOT/dsv4-0731-w8a8-dspark`（默认 /data1/models）——**自量化产物**，
  无法自动下载；配方在包内 `quant/`（bf16 原模型 → W8A8 + DSpark 张量）
- 四个运行时补丁（inner/）：triton 后端路由、dflash renorm、DSpark torch accept、
  **moe_align 根修**（gfx928 上预编译 sgl_kernel 输出垃圾 → VMFault 的根因修复）
